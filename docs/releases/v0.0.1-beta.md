# Mate4Mobile 0.0.1 Beta

The first public beta of Mate4Mobile: a self-hosted web app that gives your existing TeslaMate history a home on your phone and desktop.

## Testing status — please read first

This started as a project for my own use. My TeslaMate installation was set up using the **Proxmox Community Scripts**, and Mate4Mobile runs in that **LXC container**. That is the only deployment I have personally used and tested so far.

**I have not personally checked other installation methods or deployments yet.** Docker/Compose and native setup instructions are provided for beta testers. Automated app tests, synthetic Docker installer checks and browser previews are separate from real-world deployment testing. Please treat this as an early beta and keep a backup and rollback path.

## Included

- Vehicle overview, battery history and a combined driving/charging timeline.
- Journey maps with linked speed, power and battery charts.
- Charging history, energy and recorded-cost views.
- Configurable vehicle imagery, distance units and display currency.
- Mobile Home Screen installation and desktop layouts.
- Installation guides, restricted database-reader setup, domain/Caddy and optional TinyAuth guidance.
- A copyable AI-assisted setup prompt, plus an AI development disclosure.

## Try it and install

[Try the synthetic demo](https://itchyparrot53.github.io/mate4mobile/demo/) before connecting your own data. It requires no sign-in or installation.

Read the [README for this beta](https://github.com/itchyparrot53/mate4mobile/blob/v0.0.1-beta/README.md) and choose the [Docker guide](https://github.com/itchyparrot53/mate4mobile/blob/v0.0.1-beta/docs/INSTALL.md) or [native Node/systemd guide](https://github.com/itchyparrot53/mate4mobile/blob/v0.0.1-beta/docs/NATIVE.md). To get this exact version:

```bash
git clone --branch v0.0.1-beta https://github.com/itchyparrot53/mate4mobile.git
cd mate4mobile
```

Then follow the guide for your deployment. Existing users should use the [upgrade instructions](https://github.com/itchyparrot53/mate4mobile/blob/v0.0.1-beta/docs/OPERATIONS.md), not rerun initial setup. Docker images are built locally from source; no prebuilt registry image is published.

## Downloads

- **Source ZIP:** application, installer and documentation. Extract and follow the installation guide; it contains no private configuration.
- **Website ZIP:** static showcase and synthetic demo only. It is not the private dashboard server.
- **Brand kit ZIP:** original brand assets and included attribution files.
- **SHA256SUMS.txt:** checksums for these three archives.

The app code and original branding are MIT licensed. Tesla vehicle imagery has separate rights and attribution notices.
